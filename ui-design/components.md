# 组件与状态矩阵（SlideCraft UI）

> 令牌定义见 `DESIGN.md`；本文件只定**交互状态与反馈**。所有状态必须有可见变化（禁「点了没反应」）。

## 通用状态（每个可交互组件都要定义）

| 状态 | 视觉 | 说明 |
|---|---|---|
| default | 令牌原值 | — |
| hover | `bg → surface-alt`；主按钮 `accent-strong → #1553D6` | 过渡 120–160ms |
| active/pressed | 再深一档 + `transform: scale(.99)` | 触感反馈 |
| focus-visible | 2px `accent` 外描边 + 2px 偏移 | **键盘可达**，不得只靠颜色 |
| disabled | `opacity .5` + `cursor: not-allowed` | 禁用需给 tooltip 说明原因（如「未配置模型」） |
| loading | 文字→骨架/旋转，控件锁定但保留宽度 | 防布局跳动 |

## 关键业务组件

| 组件 | 状态 | 设计要求 |
|---|---|---|
| **步骤条**（6 步） | active / done / pending / error | active 用 `accent-strong` 徽标；done 用 `accent-soft` 对勾；error 用 `danger` + 可点击重试；**已完成步骤可回跳** |
| **缩略图网格** | 未选 / 已选 / 生成中 / 失败 / 可编辑 / 图片直通 | 已选 = 2px `accent` 描边 + `accent` 10% 底；生成中 = `accent-soft` 呼吸动画；**可编辑/图片直通用角标文字明示**（不得只靠颜色） |
| **单页大图预览** | 加载 / 就绪 / 失败 | 就绪后支持 2x/4x 放大、`‹ n/N ›` 翻页、[✦ 优化本页] |
| **成本揭示** | 预估 / 进行中 / 已结算 | 数字一律等宽；冻结与结算分开显示（`冻结 175 → 结算 175`）|
| **转可编辑**（手动触发） | 未选页 / 已勾选 / 转换中 / 完成 / 直通 | 勾选后显示页数与预计耗时/成本；未勾选页**永不自动转换**；导出前给清单确认 |
| **风格包卡片** | 默认 / 已选 / 查看中 | 「开始生成」时才绑定；卡片显示分类角标与预览图 3 张（简介只在详情页展示） |
| **账本表** | — | 表头 `surface-alt`；行分隔用 `divider`；金额等宽右对齐 |
| **空状态** | 无项目 / 无风格 / 无记录 | 一句说明 + 一个主按钮（不要空白页） |
| **错误态** | 模型未配置 / 调用失败 / 解析失败 | 明确「缺什么 + 去哪填 + 怎么重试」，禁止只显示 code |
| **Toast** | info / success / warn / error | 右上角，4s 自动消失；错误必须可复制详情 |

## 暗色可切（Phase 2）

令牌级覆盖即可，不需重做组件：`bg #12151C`、`surface #1A1E27`、`surface-alt #222634`、`border #2C3241`、`ink #E8EBF2`、`ink-sub #A3AAB8`、`accent` 提亮到 `#4C93FF`（暗底上白色的对比需求下降，可用更亮蓝），其余语义色同步提亮。实现方式：CSS 变量 + `data-theme="dark"`，Tailwind v4 通过 `@theme` 引用变量。
