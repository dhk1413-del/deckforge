12 · 接入代码（复制即用）

Tailwind v4：入口 CSS @import "./tailwind.theme.css";；非 Tailwind 项目直接 @import "./app.css"。

/* ui-design/tailwind.theme.css（节选） */ @theme { --color-neutral: #F1F6FD; /* 页面底 */ --color-surface: #ffffff; /* 卡片 */ --color-border: #E3EBF9; /* 描边 */ --color-ink: #101828; /* 主文字 */ --color-primary: #2068F0; /* 按钮填充 / 白底蓝字 */ --color-accent: #3B8DF7; /* 图标 / 描边 / 选中（不做白字底色） */ --color-accent-tint-ink: #1D5FD8; /* 浅蓝底上的蓝字 */ --font-mono: "JetBrains Mono", ui-monospace, monospace; /* 数字 */ --radius-md: 12px; }
