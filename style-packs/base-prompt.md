# 整页生图 Prompt 拼装模板

> 用法：本模板 + `layouts/<布局>.md` + `styles/<风格>/prompt.md` + `styles/<风格>/style.md` 的令牌 + 页面内容 JSON
> 拼装为一条 prompt，交给生图供应商（阿里百炼）。

## 模板（按此顺序输出，实测顺序影响遵从度）

```
【任务】生成一张 16:9 的整页 PPT 幻灯片图片，只生成这一页，不要生成多页或缩略图阵列。

【版面结构】（来自 layouts/<布局>.md）
- 按以下槽位摆放内容，严格保持层级与相对位置：<逐槽位列出来自布局文件的 slot>

【视觉风格】（来自 styles/<风格>/prompt.md）
<画面语言：底材/配色/图形语言/配图倾向/元素密度/留白/光影>

【配色与字体层级】（来自 styles/<风格>/style.md）
- 背景 <bg>；卡片/色块 <surface>；正文 <ink>；强调色 <accent>；次要强调 <accent2>
- 标题层级由大到小共 3~4 级；正文统一字号；数字可用等宽字形

【必须上屏的文字（逐字复制，不得改写、增删、翻译）】
1) 标题：「<title>」
2) 副标题：「<subtitle>」
3) 模块标题 A：「<h1>」；正文要点：「<点1>」「<点2>」「<点3>」
4) 模块标题 B：「<h2>」；正文要点：「<点1>」「<点2>」
5) 数字与专有名词必须原样保留：<must_keep 列表>

【硬约束（Negative）】
- 不要水印、不要 logo、不要页码、不要二维码、不要作者署名、不要乱码
- 文字必须清晰可读、不重叠、不超出画布边缘、不被裁切
- 不得改写文字、不得用同音字/近形字替换、不得凭空添加文字
- 不要出现额外的装饰性英文、不要出现「Lorem ipsum」类占位文本
- 所有元素必须在画布内（含 2% 安全边距）

【输出】16:9，<2K=2048×1152 / 4K=4096×2304>
```

## 提高中文文字准确率的四条经验（写进模板的硬约束里）

1. **逐条给出文字并加书名号/引号**：模型对「引号内文字」的复制遵从度显著高于段落里的散字。
2. **显式声明字号层级**：告诉它「标题 > 模块标题 > 正文」三级，避免把所有字画成一样大。
3. **限制页内字数**：单页上屏文字建议 ≤120 字（对标实测：文字越密，错字率越高，图表标签尤其容易画错）。
4. **数字与专有名词单独列 `must_keep`**：这是生成后做文字校验（OCR 回读 vs 源稿）的比对基准。

## 生成后的 Gate（脚本判定，非 AI 自评）

| Gate | 判定 |
|---|---|
| 文字保真 | OCR 回读 vs 源稿 + `must_keep` 逐字比对，异常项定位到区域 |
| 分辨率一致 | 同项目所有页尺寸完全一致（防止保留素材页被换画布） |
| 画面完整性 | 是否有大面积空白 / 文字贴边被裁 / 明显乱码块 |
