# 画面语言：商务蓝金汇报风

## 底材与配色
纯白底，深蓝主色（#1D4ED8）用于标题装饰线与模块底条，金色（#B58A3C）仅作细线与编号点缀（面积很小）。

## 图形语言
规整的矩形模块、细分割线、直角或微圆角；图表用深蓝单色（必要时加金做次序列）；允许页眉一条深蓝细条。

## 配图倾向
**默认不用照片**；如需配图，选「明亮、正式、低饱和的商务/政务场景摄影」，统一去色偏、不要人脸特写。

## 元素密度与留白
中等；模块间留白 ≥20px；页面四周留白 ≥56px，保证"能打出来贴墙上"的整洁感。

## 光影
平光、无阴影；严禁投影、发光、玻璃拟态等效果。

## 中英关键词（可粘贴给生图模型）
clean white background, formal corporate report deck, deep navy blue accent, subtle gold hairline details, symmetric modules, serif headline, sans-serif body, data table with navy single-color bars, print-ready, generous margins, 2K, 16:9

## 负向词（必带）
watermark, logo, page number, signature, extra decorative English text, lorem ipsum, drop shadow, gradient glow, glassmorphism, large gold blocks, cluttered collage, garbled characters, distorted text, cropped text
