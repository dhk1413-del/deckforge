# 画面语言：双蓝绿清新汇报风

## 底材与配色
纯白底（#FFFFFF），内容页用浅蓝卡面分区（#F0F7FE / #E8F0F8 / #DCE8F4）。
主色深蓝 #0A61BC：模块底条、编号圆点、图表主序列、图标块；更深的 #07498D 用于横带与大色块。
**封面 = 深色视觉底**（近黑 #0B0F16 + 3D 球体/光环/星尘一类主视觉图），标题压在一条**黄绿横幅**上。
**章节/过渡页 = 整幅深蓝渐变**（#0A61BC → #277DD6），可叠一块白色内容区。
**点睛黄绿 #92C248** 只落关键数字、编号圆点、图表第二序列与强调线，一页 ≤3 处。
次级亮蓝 #5FA6F1 用于浅色带、图标底、图表浅序列；标题近黑 #1D1D1A，正文中灰 #666666。

## 图形语言
直角矩形分区 + 8~12px 微圆角卡片 + 实心圆形编号点（01/02/03）+ 胶囊小标签。
深蓝→亮蓝线性渐变用于色块与图表；细分割线 1pt，强调下划线 3pt（绿或蓝）。
图标线性扁平 24×24，统一描边。装饰只允许浅蓝圆环/斜切几何。

## 配图倾向
封面允许深色 3D/深空主视觉图（球体、光环、星尘）；内容页默认不用照片，如需配图选明亮干净低饱和的校园/实验/办公场景。

## 元素密度与留白
中低密度：一页 3~4 个模块；卡片间距 ≥20px，四周留白 ≥52px。
招牌版式 = 左侧编号列 + 右侧内容列；或中心主题圆 + 三栏环绕。

## 光影
卡片允许克制投影（0 6px 18px rgba(10,97,188,.14)）；封面深色主视觉图自带光效，章节渐变面不投影。
内容页严禁霓虹发光、玻璃拟态、大面积模糊光斑。
