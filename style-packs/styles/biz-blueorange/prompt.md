# 画面语言：双蓝橙活力汇报风

## 底材与配色
纯白底（#FFFFFF），内容页用浅蓝卡面分区（#EEF3FE / #E0E9FB / #D6E2FB）。
主色亮宝蓝 #3B75FE：模块底条、编号圆点、图表主序列、图标块。
**封面 = 白底 + 画面下 1/3 一条贯通全宽的深蓝横带（#0046EA，成块、占画面约 1/3 高，不是一条细边线）**，
橙色小标签压在其上。
**章节/过渡页 = 整幅亮宝蓝渐变**（#3B75FE → #6995FE），可叠一块白色内容区。
点睛橙 #FFA615 只落关键数字、编号圆点、图表第二序列与强调下划线，一页 ≤3 处。
标题近黑 #1D1D1A，正文中灰 #666666。

## 图形语言
直角矩形分区 + 8~12px 微圆角卡片 + 实心圆形编号点（01/02/03）+ 胶囊小标签。
亮蓝→深蓝线性渐变用于色块与图表；细分割线 1pt，强调下划线 3pt（橙或蓝）。
图标线性扁平 24×24，统一描边。装饰只允许浅蓝圆环/斜切几何（透明度 ≤30%）。

## 配图倾向
默认不用照片；逻辑图由色块、圆点、编号、箭头构成。如需配图，选明亮干净低饱和的商务/办公场景并压蓝调。

## 元素密度与留白
中低密度：一页 3~4 个模块；卡片间距 ≥20px，四周留白 ≥52px。
招牌版式 = 左侧编号列 + 右侧内容列；或中心主题圆 + 三栏环绕。

## 光影
卡片允许克制投影（0 6px 18px rgba(0,70,234,.14)）；封面横带与章节渐变面不投影。
严禁霓虹发光、玻璃拟态、大面积模糊光斑。
