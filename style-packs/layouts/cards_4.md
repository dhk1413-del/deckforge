# 布局：cards_4（并列要点 / 卡片栅格）

- **用途**：3~4 个并列模块（能力、措施、价值、痛点）。
- **栅格**：一行 N 列（N=3 或 4，默认 4）；每列等宽、间距相等；卡片圆角与阴影由风格令牌决定。
- **槽位**（每个卡片）：
  1. `icon` 图标或图形符号（顶部，单色，与强调色一致）
  2. `head` 卡片标题（第 3 层级，一行，≤10 字）
  3. `body` 正文要点（2~4 条，每条一行，≤18 字/行）
  4. `highlight` 关键数字/短语高亮块（可选，仅第一张卡片用，避免全场高亮）
- **视觉重心**：页标题在左上；卡片视觉权重相等（**同级必须同字号、同对齐**）。
- **禁忌**：卡片之间不要互相嵌套；不要在卡片里再开小卡片；不要 5 列以上。
