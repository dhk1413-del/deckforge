# 布局：cover（封面）

- **用途**：整册首页、汇报封面。
- **栅格**：单栏，垂直居中偏上；左对齐或居中二选一（按风格 prompt 定）。
- **槽位**（必填 → 可选）：
  1. `title` 主标题（全页最大字号，占宽度 60~80%）
  2. `subtitle` 副标题 / 一句话价值陈述（主标题下方，字号约主标题 40%）
  3. `meta` 汇报人 / 单位 / 日期（底部一行，最小字号，弱对比）
  4. `brandmark` 品牌标识位（可选，右上或右下；**生成阶段默认留空**，见硬约束"不要 logo"）
- **视觉重心**：主标题；允许一个装饰性大图形或渐变块作为背景元素（不承载文字）。
- **禁忌**：不要在封面塞要点列表；不要出现目录；不要多个同等大标题。
- **字数上限**：标题 ≤20 字，副标题 ≤40 字。
