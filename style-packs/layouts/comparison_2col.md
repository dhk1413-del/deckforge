# 布局：comparison_2col（左右对比）

- **用途**：A vs B、现状 vs 目标、方案一 vs 方案二。
- **栅格**：两列等宽，中间一条分隔（细线或色块）；可选顶部一行「对比维度」标签。
- **槽位**：
  1. `title` 页标题
  2. `col_a_head` / `col_b_head` 两侧栏头（可用强调色块反白）
  3. `col_a_items[]` / `col_b_items[]` 逐条要点（**两侧条数应相同**，便于逐行对齐）
  4. `verdict` 结论条（底部一行，可选，用强调色）
- **视觉重心**：两侧对称；用颜色而非字号区分两侧。
- **禁忌**：不要两侧字体/字号不一致；不要一侧 5 条一侧 2 条（视觉失衡）。
