# 布局：data_chart（数据 / 图表页）

- **用途**：带数据的页面（柱状/折线/环形 + 结论）。
- **栅格**：左文右图 或 上图下文（默认左 40% 文字 / 右 60% 图表）。
- **槽位**：
  1. `title` 页标题（结论式标题，如"三地市签约量同比增长 32%"）
  2. `chart` 图表主体（柱状/条形/环形/折线，颜色只用风格令牌的 accent 与 accent2）
  3. `labels` 数据标签（**每个数据点必须带数值**，字号统一，等宽数字更佳）
  4. `insight` 右下角结论要点（3 条以内，每条 ≤20 字）
  5. `source` 数据来源（底部最小字号，可选）
- **视觉重心**：图表；文字为辅助。
- **禁忌（高发错误区）**：图表项 ≤6 个；**不要在图表里堆长句标签**（实测：小字标签是整页错字率最高的地方，建议标签 ≤6 字）；不要用超过 3 种颜色；不要省略坐标轴单位。
